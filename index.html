Edit access on this device

Viewing needs nothing. To save, paste a GitHub token with only the gist scope — it can touch your gists and nothing else (no repos, no account). It's stored only in this browser. On a work laptop, set an expiry and use Forget when you're done.

Make one at github.com → Settings → Developer settings → Personal access tokens. Classic token, tick only gist.
